# Голосовое управление

При ошибке распознавания можно ввести команду в той же панели и нажать «Выполнить» (или Enter). «Повторить запись» запускает новую сессию. Редактирование поля отменяет текущую запись; после ошибки поздние события браузера игнорируются. Текстовый ввод сохраняет режим поиска или помощника и контекст выбранного набора.

Ошибка `network` означает недоступность сервиса распознавания браузера. Она не устраняется переносом сайта или переименованием файлов. В текущем встроенном браузере эта ошибка воспроизводится; успешное распознавание живой русской речи не подтверждено. Текстовое выполнение работает независимо от сервиса. Локальная модель распознавания и серверный API к сайту не подключены.

Микрофон в шапке сразу начинает распознавание после разрешения браузера. Отдельного окна с меню и подтверждения команды нет. Небольшое всплывающее поле показывает промежуточную и итоговую фразу. После окончания распознавания действие выполняется автоматически.

- Общие команды: «Открой атлас данных», «Перейди в конструктор данных», «Открой исследования», «Открой доклад о полимерах».
- Поиск: «Найди полимеры». В поле поиска есть отдельный микрофон: он принимает свободный поисковый запрос без командного префикса.
- Помощник: «Спроси помощника: что такое ЦОД?». У формы помощника есть собственный микрофон для свободного вопроса. Выбранные материал, набор данных, показатели и фильтр сохраняются.

Неподдерживаемая общая команда показывает «Команда не распознана» и не меняет раздел. Повторное нажатие на микрофон останавливает запись и отменяет выполнение. Закрытие уведомления, Escape, смена раздела и скрытие вкладки тоже останавливают активное распознавание. Поздние события отменённой записи игнорируются.

Используется браузерный Web Speech API (`SpeechRecognition` или `webkitSpeechRecognition`), язык `ru-RU`, одна фраза, до 20 секунд. Нужны HTTPS или доверенный localhost и разрешение на микрофон. Поддержка API и русской речи, доступность сервиса зависят от браузера. Браузер может передавать речь своему сервису; может требоваться интернет. Сайт не сохраняет аудио. Внешняя языковая модель и платные API не подключены; помощник отвечает по опубликованному корпусу.

`node --test tests/*.test.mjs` включает проверки распознавателя команд, автоматического выполнения по финальному результату, отображения промежуточного текста, неизвестной команды, голосового поиска и передачи вопроса с сохранением контекста. Используются имитированные события распознавания. Реальная речь и разрешение на пользовательский микрофон автоматически не тестируются.

[Документация SpeechRecognition на MDN](https://developer.mozilla.org/en-US/docs/Web/API/SpeechRecognition).
