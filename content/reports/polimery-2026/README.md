# Полимеры: локальная цифровая версия

Полный текст 44 страниц; 16 разделов; 6 числовых наборов и 10 справочных транскрипций; страновой набор ранее подготовлен в конструкторе. Оригинальные рисунки сохранены постранично.

Упаковано по atre-format 1.1. Справочные CSV сохраняют текстовые фрагменты, не имитируя восстановление сложных ячеек. Issue, PR, публикация и обновление GitHub исключены по поручению пользователя. Источник GitHub вернул404; использован локальный PDF с SHA-256 из реестра.
