# Изменения проекта АТРЭ

## Не выпущено

### Публикации и новости — 20.11.2026

- По следующим пяти аннотациям уменьшен блок «Актуальное», кнопки геосравнения оформлены как в «Исследованиях», выровнены поля каталога и атласа. Голосовая панель принимает команды фильтрации и сохраняет действующие условия в текущем разделе.
- По семи браузерным аннотациям выровнены блоки главной и уменьшены элементы управления каруселями. В каталог добавлен диапазон дат публикации, в атлас — переключатель представлений с подвижным индикатором. «Новости» стоят первыми в меню. Обновлены голосовые команды для новостей, актуального, публикаций и тегов, тексты новостей включены в поиск.
- По браузерным аннотациям карточки новостей целиком ведут на локальные страницы с текстом и источниками. На главной добавлено «Актуальное» с новостями и свежими публикациями, два блока исследований объединены, смена докладов ускорена до пяти секунд с плавным переходом.
- По поручению пользователя добавлены ключевые теги к публикациям, переход из тега к подборке материалов и поиск по ключевым словам.
- На главной появился блок из трёх докладов с оригинальными обложками, ключевыми выводами и управляемой сменой слайдов.
- Добавлены раздел новостей с подборкой официальных публикаций АТРЭ и панель со ссылкой на Telegram.

### Сценарий баланса полимеров — 20.11.2026

- По поручению пользователя в цифровой доклад добавлен сценарий изменения потребления при фиксированном производстве. Схема обновляется при выборе полимера и изменении спроса. По кнопке доступны опубликованный баланс за 2024 год, условный результат и порог равновесия. Источник — таблица 9 на с. 30.

- В README пакета полимеров сохранено историческое ограничение этапа и добавлено актуальное состояние публикации.
