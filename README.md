# АТРЭ · Перспективная версия

Самостоятельная демонстрационная версия по модели 2 UX/UI-аудита. Не является fork и не изменяет atre-site. Удалённая ветка публикации: `design/perspective-v1`. На момент подключения практики 19.11.2026 локальная рабочая ветка — `published/annotations-2026-11-19`; актуальную ветку всегда проверять через Git.

## Запуск и сборка

Нужен Node.js 22 или новее. Установка пакетов не требуется.

```sh
node scripts/build.mjs
node --test tests/*.test.mjs
node scripts/serve.mjs
```

Открыть http://127.0.0.1:8173. Публиковать содержимое dist/ в корне домена. Навигация использует hash URL. Кабинет: /#/employee или /employee/.

## Возможности

- Витрина «Практики АТРЭ» на главной показывает девять направлений консалтинга со схемами и ссылками.

- В «Об АТРЭ» вложены «Команда» с оригинальными портретами и «Проектный опыт» с поиском и фильтрами. «Консалтинг» группирует экспертизу по практикам, секторам и темам исследований. Источники и контрольные суммы материалов из презентации «Опыт и команда» указаны в `data/agency-expertise.json`.
- «Для СМИ» содержит форму запроса комментария, отдельную кнопку почтового шаблона и ссылки на публикации. Штатный локальный сервер принимает запросы и сохраняет их в `.local/press-requests/` вне сборки. На статическом хостинге доступен почтовый шаблон.
- Демонстрационная подписка в клиентской зоне открывает пример «Региональные инвестиции» в том же браузере. Значения условные, платёж не проводится.
- «Аналитическая платформа» объединяет Атлас данных и Конструктор. Каталог включает данные докладов и бюджеты регионов из «АТРЭ ГеоЭкономики». Наборы можно фильтровать по отрасли, направлению и доступу, просматривать в таблице, на графике или на карте при наличии геопривязки, сопоставлять на двух независимых панелях и выгружать срезы. Старые ссылки открывают соответствующие наборы и срезы.

- 12 докладов и один мониторинг, тематические узлы и каталог 30 проектов.
- Ключевые теги публикаций и подборки по тегу. На главной сменяются три доклада с оригинальными обложками и краткими выводами.
- «Актуальное» на главной чередует новости и публикации. В разделе «Новости» каждая карточка ведёт на локальную страницу с текстом и источниками из `data/news.json`. Панель в подвале ведёт в Telegram АТРЭ.
- Переключатель над первым экраном открывает исследовательскую главную по `#/` или консалтинговый вариант по `#/?view=consulting`. Обе версии используют общее меню.
- Страница `#/request` принимает вопросы и заявки на консультационные работы или исследования. Штатный локальный сервер сохраняет обращения в `.local/consulting-requests/`. Для отправки в АТРЭ доступен отдельный шаблон письма.
- Прогноз ЦОД и энергетики: сравнение до трёх из пяти территорий по трём показателям, профиль и CSV сравнения.
- Поиск в цифровых докладах, 264 страницах PDF, таблицах и проектах, с формами слов и числовыми значениями. Результаты по названиям, ключевым словам и показателям наборов открывают их на аналитической платформе.
- Помощник без внешней модели: извлечение фрагментов, сравнения территорий и ссылки на источники.
- Спортивный калькулятор: потеря коммерческой выручки и необходимый рост доходов в дни матчей.
- Демонстрационный кабинет без авторизации: три внешние системы с самостоятельным входом, подборки в браузере и экспорт.

## Происхождение и обновление

data/source-corpus.json содержит открытые материалы из сохранённых публикационных пакетов. data/provenance.json содержит исходные относительные пути и SHA-256. public/materials/ — PDF и CSV; public/brand/ — фирменные SVG; public/fonts/ — Raleway с лицензией OFL; public/geo/countries.json — геометрия Natural Earth. Локальные D3 Array и D3 Geo в public/vendor/, лицензии указаны в заголовках файлов.

Для добавления материала заполнить materials с реальными названием, датой, тематикой, текстом и ссылками. Файлы поместить в public/materials/<id>/, добавить контрольные суммы в provenance. Для показателей сохранять единицы, период, статус (факт/прогноз/сценарий), ограничения и страницу источника. Затем выполнить сборку и тесты. Не дописывать непроверенных авторов, результаты проектов и отсутствующие значения.

## Ограничения

2025 в энергетическом атласе — прогнозная база. Разность темпов потребления и мощности не равна дефициту. Точки карты условно обозначают территории, не ЦОД. Границы энергосистем и округов различаются. В мониторинге доступны Россия и Казахстан; остальные страны ожидают загрузки, это не нули. Индекс цен Казахстана 228,2% относится к августу 2026 и базе декабря 2020. OCR сверять с PDF. Темы проектов предварительные; опубликованные названия не подтверждают результаты.

Помощник не ведёт произвольный генеративный диалог. Реальной авторизации, закрытых документов, персональных данных, серверных заметок и внешних API нет. Подборки хранятся только в localStorage текущего браузера. Внешние системы открываются независимо, без SSO.

Секреты и переменные окружения не нужны. .openai/hosting.json содержит только идентификатор отдельного Site и настройки статической публикации. Исходники размещены в публичном репозитории GitHub по запросу владельца.

Крупнейший PDF хранится в исходниках частями data/assets/*.part1–3 из-за ограничения передачи GitHub. Сборка объединяет их в исходный PDF и проверяет SHA-256; содержимое документа не меняется.

Демонстрация доступна любому со ссылкой без входа; HTML содержит noindex/nofollow. Это указание поисковым системам, а не ограничение доступа. GitHub-репозиторий открыт по запросу владельца.


## Публикация на GitHub Pages

Workflow .github/workflows/pages.yml собирает и проверяет проект из ветки design/perspective-v1, затем scripts/prepare-pages.mjs адаптирует адреса файлов для /atre-next/. HTML сохраняет noindex/nofollow. Публикация выполняется через GitHub Actions; результат доступен по адресу https://aievich.github.io/atre-next/ после успешного deployment.


## Интерактивные исследования и данные

Пробная версия аналитической платформы доступна по `#/geoanalytics-preview` и по кнопке в действующем разделе. Она принимает JSON до 2 МБ с `schemaVersion: 1`, объектом `passport`, массивами `series` и `observations` до 5000 записей каждый. Откройте встроенный пример и скачайте пакет JSON как шаблон. Бюджетный пример использует открытый срез сайта, спортивный содержит явно обозначенные условные данные. Загруженный пакет остаётся в памяти вкладки. Кнопка возврата из пробной версии открывает прежний адрес с параметрами среза. Формат версии 1 используется в прототипе до согласования обмена с платформой.

Добавлены конструктор наборов, географические слои, демонстрационная клиентская зона и редактор запросов помощника. Доклад о полимерах доступен по `#/study/polimery-2026`: полный текст 44 страниц, интерактивные показатели и оригиналы страниц. Текст доклада не редактировался при улучшении читаемости.

Для публикационной сборки после build выполнить `node scripts/prepare-pages.mjs /atre-next/`. Адаптация обрабатывает все модули и вложенные данные; локальный запуск остаётся в корне домена.

## Работа через Codex и Git

Открывать существующую папку `D:\Projects\ATRE-Site` как основную папку локального проекта Codex. Сначала читать инструкции и проверять `git status --short --branch`; сохранять незакоммиченные изменения. Уточнять поручение или адресную аннотацию, править исходники, выполнять соответствующие проверки, обновлять журнал и показывать diff. Комментарии к интерфейсу проверять в браузере; ограничения проверки указывать явно.

Git уже существует; `git init` не нужен. Origin: `https://github.com/Aievich/atre-next.git`. Локальная ветка на дату подключения отслеживает `origin/design/perspective-v1`. Другие локальные ветки сохранены и могут указывать на прежние коммиты; не переключаться на них автоматически.

Завершённые изменения фиксировать отдельными осмысленными коммитами после проверки. По принятому порядку коммиты выполняет пользователь по подготовленному агентом явному списку файлов, пока отдельно не разрешены локальные коммиты агента. Не применять слепой `git add -A`, отбрасывание правок и переписывание истории. Push и публикация требуют отдельного поручения; push в `design/perspective-v1` автоматически публикует сайт. Новый обязательный порядок PR и новые hooks этим подключением не вводятся.
