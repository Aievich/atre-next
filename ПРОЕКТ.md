## Границы подключения

Сайт не перенумеровывается и не превращается в папку комплекта. Сохраняются src, data, content, public, scripts, tests, dist и имеющаяся публикация. Отдельный исходный atre-site не входит в этот репозиторий. Папки и файлы практики не копируются целиком. Единственный новый раздел — docs/checks для итогов проверок.

В комплекте отсутствует Инструкция-для-команды.md, упомянутая README и AGENTS комплекта; по манифесту 54 остальных файла прошли SHA-256. Подключение основано на доступном навыке, общих правилах, шаблонах и согласованном пользователем плане. Отсутствующая инструкция не считается прочитанной.

Комплект — внешний локальный ресурс, не зависимость сборки. Его путь указан для этого компьютера; другим участникам нужен доступ к своему экземпляру комплекта, а исходники сайта запускаются без него. Перед отправкой новых документов в публичный GitHub пользователь проверяет допустимость локальных путей и состав коммита.
